通过浏览器添加到桌面

当前浏览器尚未提供系统安装弹窗。请按下方步骤操作；网页不能代替你点击浏览器菜单。

  1. 打开浏览器菜单

    点击浏览器顶部或底部的“⋮”“…”或菜单图标。

  2. 查找桌面入口

    选择“添加到桌面”“添加到主屏幕”或“安装应用”。部分浏览器放在“工具箱”“更多”或“添加至”中；具体名称以你的浏览器为准。

  3. 确认后回到手机桌面

    找到“拾日”图标。仅添加快捷方式时，打开后仍会进入浏览器。

菜单中也没有此功能？复制下方网址，到 Chrome 中打开再安装。不同浏览器的数据不互通；已有记录请先导出备份。

账号接入 · 待微信应用审核

微信登录申请指引

安装到桌面不会自动获得微信登录能力。先确定使用场景，再申请对应类型，避免重复申请。

1. 选择正确的应用类型

电脑网站扫码：微信开放平台“网站应用”。安卓 APK 内唤起微信：微信开放平台“移动应用”，还需正式包名与签名。微信内网页授权：使用具备相应权限的公众号。当前交付的是 PWA，没有 APK 包名和签名，不应当作移动应用提交。

2. 注册账号并查看主体资格

在微信开放平台注册账号，按后台要求完成开发者资料、主体认证和应用资料。个人或组织可申请的能力、材料、费用与审核要求以微信后台当时提示为准；普通个人微信账号不是应用的 AppID。

3. 准备应用资料与可验证地址

应用名可填“拾日生活日志”，说明为“记录个人生活照片与笔记，生成多周期复盘，生活内容在设备本地保存”。准备图标、截图、真实主体资料、隐私说明，以及所选类型要求的域名或安装包。当前私有站点有 ChatGPT 访问限制，不能假设它可直接通过微信域名验证；正式回调地址需在认证服务部署后确认。

4. 审核通过后配置凭据

获取应用 AppID，并在服务端的密钥配置界面保存 AppSecret。不要把 AppSecret 发到聊天、写入网页或代码仓库。完成后才能接通真实微信授权、回调校验和安全会话，再在安卓手机验收。

微信审核通过和真实登录测试完成前，本页不会显示可用的微信登录按钮。账号认证需要与微信及认证服务器通信，生活内容仍应留在本地。
