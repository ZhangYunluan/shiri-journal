# 拾日 0.5.1 昵称搜索使用与验收

2026-10-12。用户已在真实 shiri-dev 环境部署 001_social_fixed.sql 与 002_nickname_search.sql，并确认验证 SQL 通过。本次仅合并客户端与本地测试/源码参考，**没有运行生产数据库迁移，不需要重复执行 SQL**。

## 使用

1. 先在旧版设置中导出完整备份，再覆盖安装 0.5.1 APK。包名 cn.shiri.life，versionCode 8，使用旧版同一签名。不要卸载旧版或清除应用数据。
2. 用现有邮箱会话登录或恢复登录，底部“好友”→上方“好友”。自己的昵称可在账号卡片“修改昵称”中修改，支持同名。
3. 被搜索的一方点击“允许通过昵称找到我”。默认关闭；之后可随时关闭，不影响已有好友关系和已有授权。
4. 搜索方输入 2–48 个字的昵称，点击“搜索好友”。结果最多 10 位，优先完全匹配，再按前缀/包含匹配；同名用账号末 6 位识别码核对。
5. 在对应结果中填写独立的申请留言，点击“发送好友申请”。目标使用返回的真实 UID，无需手工输入完整账号 ID。对方在“申请”中接受或拒绝。
6. 成为好友后，自己的私人日记默认不开放。需要主动发布并单独设置开放范围，对方才可看见。删除或屏蔽会撤销好友授权，解除屏蔽不会自动恢复。

- 最后确认本地照片、分类、日报/周报、备份导出仍可使用。若未部署 shiri-media，可先测试文字近况；本次没有新增或部署照片服务。
