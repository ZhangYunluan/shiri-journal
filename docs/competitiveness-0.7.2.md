## 改动

- `src/friend-timeline.mjs`：用递增请求序号拒绝迟到回复，即使连续下一张再上一张回到同一索引；关闭/退出时释放当前大图 URL；每次切换最多保留一个大图；关闭期间返回的图片立即释放。401/403/404 沿用整体权限失效处理，清理缓存、移除图片点击并停止队列；新增图序和单图按钮禁用。
- `src/beta-analytics.mjs`、`life-app.mjs`：以实际展示的聊天或复盘识别查看事件，不记录聊天内容或附加用户信息。
- `tests/beta-analytics.test.mjs`、`scripts/verify-friend-gallery.mjs`：针对上述真实缺陷的回归。
- Android 版本与输出脚本：0.7.2-release / versionCode 23，原包名、原证书。

## 部署与剩余边界

无需额外 SQL；无需变更照片或好友云函数。没有新增依赖、付费 API 或云服务。
统计当前仅为同意后的本机计数，不能据此宣称已获得后台用户留存数据。可选 `shiri-telemetry` 接收函数和部署说明早已存在；未来启用需先实际验证身份、管理员日志访问与保留期，再配置客户端并重新征得同意。本次未自动部署、未购买服务。
真实安卓设备升级、系统相册权限与后台调度、低端机性能、当前版本真实双账号与云存储回归仍需实测。既有双账号结果不作为新版本实机验收。
