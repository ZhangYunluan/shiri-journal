# 拾日 0.8.3 · 开源内测

拾日帮助你审核照片、保存生活片刻，并通过日历和复盘回看自己。亲密好友只查看明确授权的内容。

本次公开源码默认不绑定运营环境，提供合成数据交互演示、开发与部署说明。既有 Android 内测 APK 使用原运营 CloudBase 服务，和空配置源码演示有所区别。自行构建调试包需要自己的配置，不能覆盖正式版。

0.8.3 修复本地邮箱验证码并发和挑战状态问题。未复现“大小写变体产生不同云端 UID”的漏洞，真实邮箱规则与验证码边界仍待受控账号验证。

版本 0.8.3-release，versionCode 29，正式包名 cn.shiri.life。请同时下载 SHA256SUMS.txt 与 APK_INFO.md，核对文件来源和校验值。兼容旧签名的安装包支持系统允许的覆盖升级，请先从旧版导出备份，保留备份后再按系统提示安装；不要卸载旧版或清除数据。若系统无法确认安全性或来源，请先联系维护者核实。

早期内测尚不代表全部机型、云端权限场景和数据恢复均已通过验证。iOS 未生成 IPA，HarmonyOS NEXT 无 HAP。服务商和模型的免费额度可能变化，不保证持续免费。
