# 环境隔离

公开源码默认云配置为空。演示在 demo/ 使用独立存储，不连接认证、相册、好友或模型服务。

开发调试使用自己的 CloudBase 环境，公开配置写入被忽略的 .local/dev-cloud.json。开发包 cn.shiri.life.debug 与正式包 cn.shiri.life 分开安装。不要对真实内测用户环境执行开发写入或迁移。

生产构建需要运营者自己的认证来源、HTTPS 路由、私有桶、RLS、服务端限频、隐私说明及发布签名。服务端凭证只放云函数环境变量。本仓库不会自动部署或开通资源。

若凭证曾暴露，资源持有人应检查并撤销，源码删除不能代替凭证轮换。不要在公开 Issue 讨论实际密钥或用户内容。
