# 手机安装与使用

Android 安装包从发布者实际上传的 GitHub Releases 或其确认过的内测渠道获取。先核对版本、文件校验值和签名来源。系统无法确认来源或报告风险时，请联系维护者核实。

当前公开源码是 0.8.3，README 中的演示仅展示本地整理与规则复盘，不能代替 Android 原生照片权限测试。独立演示没有账号与云服务依赖。

同包名、同签名且版本号允许时，Android 可覆盖升级。升级前在旧版本设置中导出完整备份，保留文件，按系统提示安装。不要卸载旧版或清除数据来解决安装错误。

开发调试版使用独立包名，不能覆盖正式用户版。iOS 尚未生成可安装 IPA，HarmonyOS NEXT 尚无原生 HAP。

自动发现受系统授权与后台调度限制，可能延迟。未审核素材不会因此上传。保存片刻后仍由已有好友授权规则决定同步与访问范围。
