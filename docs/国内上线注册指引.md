# 拾日：从 APK 测试版到国内正式上线

更新于 2026-10-08。当前你没有云账号、域名或经营主体，微信应用也尚未申请。先测试本地 APK；以下服务开通后，才能连接真实账号登录与长期下载地址。注册、实名、人脸验证、合同确认和付款由你本人完成；密码、验证码、AppSecret 和云密钥不要发送到聊天。

## 1. 先注册腾讯云中国站账号

打开 [腾讯云中国站](https://cloud.tencent.com/)，点击注册，使用你长期持有的手机号或微信完成注册。进入账号中心查看实名认证入口。

你计划商业运营，先确定实际运营者。还未确定主体时可以先了解控制台，暂不购买服务器或长期套餐。主体确定后，按腾讯云控制台接受的类型和材料认证，使账号、域名、短信签名及应用运营者保持一致。不要将个人测试账户默认当成已具备全部商业申请资格。

参考：[腾讯云账号注册与实名认证指南](https://ide.cloud.tencent.com/docs/guide/product_use/account/tencent-cloud-register/)。

## 2. 确定经营主体，再办理对应资料

微信认证、短信签名和拟上架市场对申请者及材料各有要求。先在相应官方申请页核实当前允许的主体类型，再决定个体工商户或公司；不要仅为开发测试购买代办套餐。企业登记需由你在所在地政务服务或市场监管官方渠道办理。商用还需结合业务核实备案与市场准入要求，不能仅凭一个 APK 判断可以上线收费。

准备：运营者名称、联系邮箱、客服电话或联系方式、应用名称「拾日」、功能介绍。未来隐私政策需填写真实运营者，而不是保留示例名称。

## 3. 国内手机号与邮箱登录

进入 [CloudBase 控制台](https://tcb.cloud.tencent.com/)，创建上海地域环境。先查看套餐、短信费用与额度，确认后再开通，设置预算告警。

在「身份认证 / 登录方式」开启所需渠道：

- 手机号：官方短信登录目前仅支持上海地域。按引导在腾讯云短信申请签名、验证码模板，审核通过后在 CloudBase 配置；不是安装 SDK 就自动可以发短信。
- 邮箱：按控制台指引配置验证码邮件；通过真实邮箱收取并完成验证后才算接通。
- 记录环境 ID、地域以及公开客户端 ID（如果控制台提供）。这些非秘密配置可用于接入。密钥只填入对应服务的安全配置。

参考：[身份认证](https://cloud.tencent.com/document/product/876/121347)、[短信验证码前置配置](https://docs.cloudbase.net/authentication-v2/method/sms-login)、[邮箱验证码登录](https://docs.cloudbase.net/authentication-v2/method/email-login)。实际代码以已安装 Web v3 SDK 的接口为准，避免混用旧接口。

上线前还要验证错误码、验证码到期、重发限流、账户切换、退出和注销。账号认证会联网处理手机号或邮箱等必要身份资料；相册、日志和报告继续留在设备。用户不同意账号服务时，可继续使用明确允许的本地功能。

## 4. 微信登录：申请移动应用

打开 [微信开放平台](https://open.weixin.qq.com/)，注册开发者账号，按照控制台要求完成资质认证。创建「移动应用」，不要创建成仅供网页扫码的「网站应用」。按表单提交应用资料并申请微信登录能力。

Android 包名：`cn.shiri.life`。签名指纹必须以最终 APK 的证书为准，打包后在 `docs/android-verification.md` 记录公开指纹；不能填写文件 SHA-256，也不能将密钥上传到开放平台。后续升级保持同一签名密钥。

审核通过后保留 AppID。AppSecret 放在你控制的服务端密钥管理中，不能写入 APK 或前端 JavaScript。接入还包括原生微信 SDK、回调和服务端 code 兑换，需要真实安装微信的手机验收。

申请入口与资格以微信控制台实时显示为准；这里不承诺审核结果或固定费用。

## 5. 域名与长期 APK 下载地址

选好一个域名后，通过你自己的域名注册账号购买并实名。与云服务商核实网站及 APP 备案要求，网站备案与 APP 备案应分别核实。参考：[腾讯云 APP 备案常见问题](https://cloud.tencent.com/document/product/243/97691)。

正式下载推荐把唯一的签名 APK 放在国内对象存储的专用发布目录，绑定 HTTPS 下载域名。不要上传整个开发项目、`.signing`、用户备份或云配置。下载对象需要公众可读时，只授予发布 APK 必需的读取权限，不开放上传或整个桶的写权限。

下载页显示版本、大小、SHA-256、更新说明和安装说明。现有 `chatgpt.site` 地址不作为国内商业发布地址。临时局域网链接只方便你自己测试，不是公网服务。

## 6. 开通后交回的接入信息

只需提供这些非秘密信息：

1. 主体类型，以及微信申请是否获批。
2. CloudBase 环境 ID、地域、已开启的手机号/邮箱登录渠道。
3. 域名及备案办理状态。
4. 微信移动应用 AppID。

随后完成真实渠道接入、国内移动/联通/电信网络下载与登录测试、真机权限和账号隔离测试、应用市场材料，再讨论具体收费方式。当前 APK 测试版不包含支付或已开通的账号服务。
