# 拾日 0.7.1：照片入口与对话体验

## 实际修改
- `src/views.mjs`：首页、素材页添加照片使用明确按钮；问问拾日切换为专注的消息列表和底部输入区。目标与片刻选择按需展开，保留摘要预览、明确同意和服务未配置提示。回答只显示一次。复盘突出真实记录天数与条数；规划突出添加计划。
- `life-app.mjs`：对话渲染滚动到最新消息；选择摘要后保留展开位置；清空及退出账号时移除目标和问题草稿。复用原 AI 请求、同意、限流及会话逻辑。
- `life.css`：清晰照片按钮、对话布局、阅读层级与轻量第二阶段样式。没有新依赖。
- `src/cloudbase-friends-view.mjs`：好友个人主页省去重复时间线标题和说明，保留姓名、日期分组、授权照片与所有好友操作。
- Android 构建配置：包名 cn.shiri.life，versionCode 22，0.7.1-release，使用原发布证书。
- 测试：`tests/chat-layout.test.mjs`、`tests/report-refresh.test.mjs`、`scripts/verify-ux-phase2.mjs`。

## 验证
34 项针对性自动化测试通过，覆盖聊天展示/转义、同意与摘要筛选、限流/缓存、复盘数据、保存同步与批量审核回归。
隔离浏览器通过：照片按钮打开既有导入和选择器；320/390/430/1280 宽度无横向溢出；未同意时不请求模型；模拟回复显示为消息；修改摘要后撤销同意并清空旧对话；复盘与规划正常渲染。
截图在 releases/ux-phase2，使用合成数据与模拟回复，未调用真实模型，无新增 API 费用。
