# 短语音片刻：第二阶段评估（未实施）

## 代码现状
Android 为 Capacitor + Java + WebView。Manifest 没有 RECORD_AUDIO；MainActivity 只注册相册和凭据插件，没有录音插件。
现有 IndexedDB assets、导入/备份验证按图片设计，不能直接把音频塞进去当照片。现有 shiri-media 仅接受 JPEG、最大1MiB，并重新处理 JPEG 元数据；音频目前会被415拒绝。好友近况也是照片网格，没有播放器。
因此短语音本机记录工作量中等，含好友播放/撤销/备份的完整版本工作量中等偏高，不能只加一个录音按钮宣称完成。

## 推荐的最小实现
1. 先做前台、主动录制，最长60秒/单片刻一段、单声道 AAC-LC + MPEG-4（.m4a，audio/mp4），建议48kbps、上限512KiB。
2. 增加小型自有 Capacitor Java 插件调用 MediaRecorder；用户第一次点录音时解释用途并请求 RECORD_AUDIO，拒绝或永久拒绝有明确提示。仅录自己的麦克风，不申请扫描系统音频库权限，不做后台/锁屏录音服务。
3. UI 录音→停止→试听/删除/重录→原“保存片刻”。录音临时文件只在应用私有缓存；未保存不进入同步队列，取消、录音失败和过期草稿清理只处理应用临时文件。通话、切后台、权限撤销、过短录音失败均停止释放录音资源并明确提示。
4. 本地增加音频附件关联、时长/大小/校验值；优先复用 IndexedDB，但必须扩展 assets类型校验和 ZIP manifest/恢复逻辑，不能破坏现有照片附件、旧备份和跨版本恢复。最终选用新增附件表或扩展现表要在实施前确定兼容协议，不在本次擅自迁移。
5. 只在用户保存且可见范围允许时进入现有同步队列。私人日记、仅自己、未保存音频不上传。好友页面按需加载播放器，禁止自动播放。

## 云端必须补的能力（本次没有修改）
不能直接扩大现有 JPEG 接口的 MIME 白名单。需要有类型/大小/时长验证、私有对象标识及音频附件的服务端关系；服务端权限必须沿片刻和好友 grant 检查，不能信任客户端 uid。
可复用 shiri_social 的身份、好友与可见范围检查，但现有 photo/media 数据模型不等于音频协议已经存在。预计需要一次单独审核的增量 SQL/RPC、shiri-media 或独立音频路由，以及发布开始/完成的附件状态扩展。
播放器只通过鉴权接口取内容，考虑受控 Range 请求或受限小文件下载为 Blob URL。不得转为公开存储桶或长期可公开访问的 URL。删除片刻、删除好友、屏蔽及撤销后拒绝后续获取；切账号/离开页面/权限失败时停止播放、清理可控 Blob URL。已经下载的内容无法保证从对方设备抹除。

## 文件范围
- Android：AndroidManifest.xml、MainActivity.java、新 AudioRecorderPlugin.java、native-entry.mjs。
- 前端：记录编辑器、life-app.mjs、views.mjs、少量 CSS、音频附件管理。
- 数据可靠性：db.mjs、backup.mjs、moment-sync.mjs 和恢复/重试测试。
- 云端/好友：经授权后扩展业务 RPC/私有媒体服务、friend-timeline.mjs 的按需播放器和撤权测试。
不需要语音转文字、付费语音 SDK、AI 语音分析或实时通信。

## 存储与费用估算
按48kbps估算，30–60秒约180–360KB，加少量封装开销，实际以文件大小为准。
100人每人每天保存10段，30天新增约5.4–10.8GB；若每段平均被3位好友完整播放一次，月下行约16.2–32.4GB，另有请求数、数据库、函数资源及可能日志成本。重试和缓存策略会影响实际流量；删除/过期保留策略也影响存储。
这是容量估算，不是腾讯云账单报价。需由负责人按当前套餐单价/免费额度确认金额，不自动开通套餐；没有新增第三方AI/转写API费。

## 必须真机验证
Android及兼容APK的鸿蒙：麦克风允许/拒绝/撤销、来电/切后台、录音失败、长短录制、耳机播放；断网保存、恢复同步去重、照片+文字+语音混合、ZIP恢复、双账号授权与撤销、第三方访问拒绝。
WebView MediaRecorder 可作为未来网页增强方案，但必须检测 MediaRecorder/isTypeSupported 及安全上下文，不能假设全部WebView一致。本阶段优先原生系统编码以控制格式；未实施、未申请麦克风权限、没有生成录音文件或上传音频。

官方依据（2026-10-27核对）：https://developer.android.com/media/platform/mediarecorder 。RECORD_AUDIO 需运行时授权，录音生命周期需停止/释放，实际硬件兼容性需要真机测试。
