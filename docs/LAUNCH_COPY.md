# 项目介绍文案

## GitHub About

记录生活，回看自己。A personal life journal with photo review, reflections and private friend sharing.

## 中文社区介绍

我把持续打磨的生活记录小作品「拾日 Shiri」整理开源了。

它从一件小事开始，把授权范围内的照片整理成片刻，再通过日历、心情和复盘回看自己的生活。明确授权的亲密好友也能自然了解近况。

目前是早期 Android 内测，使用 HTML/CSS/JavaScript + Capacitor，后端采用 CloudBase。仓库提供不需要云账号的合成数据演示，想先体验可以直接本地运行；账号、同步和 AI 需要另行配置。iOS 与原生鸿蒙尚未完成真机验证。

欢迎试用、提 Bug，或者从文档、小屏适配和规则测试开始贡献。仓库地址请在实际发布后粘贴在这里。若你觉得有意思，欢迎 Star 关注后续进展。

## 第一批 Issue 建议

- 用不同 Android 字体和显示大小复验日期弹窗，提交脱敏截图与系统版本。
- 为周报跨月和旧分类记录补充合成测试，保证统计依据可解释。
- 改进键盘与屏幕阅读器操作，检查批量选择状态的读屏提示。
- 跟随 SETUP 在第二台电脑独立运行演示和调试构建，记录文档缺口。

每项请补充负责人、文件范围和可验证的完成条件，再标注 good first issue 或 help wanted。
