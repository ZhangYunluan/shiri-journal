# 首次照片引导与地点回填

基于 2ee09e9，分支 codex/photo-onboarding。改动前保留 .local/before-photo-onboarding.bundle；不修改正式版本号、包名、发布签名或云端配置。

## 行为
- Android 首次登录、打开当前账号本地空间后检查系统实际权限；未授权时展示“让拾日帮你整理生活”。只有点“开启照片访问”才申请系统权限。
- 授权回调后重新读取 full/partial/none，核实采集配置开启再报告成功；权限不足不调用开启配置。部分授权明确告知只能发现选定照片，新照片需补充选择。
- 点击稍后、返回键关闭、已经尝试或已有授权，都不在本机当前账号反复弹出。引导选择仅存本机 localStorage，不上传，也不进入日记备份；其他设备可以重新引导。
- 拒绝仍可文字/手动选图记录。设置保留“授权并开启”“调整相册授权”，新增明确点击的系统应用设置入口。不开启全文件、通讯录、实时/后台位置权限。
- 继续用现有分版本系统申请：Android12及以下旧媒体读取、Android13图片权限、Android14+选定图片。系统权限返回前台时暂缓重复扫描，避免抢先触发导入导致状态竞争。
- 授权后的发现、待审核和导入仍只在本机；保存片刻后才按既有好友规则同步。默认22:00，保留已有采集时间。省电/系统限制仍可能延迟任务。

## 地点
已实现的 EXIF GPS 解析与导入逻辑继续复用。对旧的待审核照片，打开编辑时先读本地EXIF，再在已有媒体位置权限下补读关联原图，不弹权限请求；不会根据画面或实时位置猜地点。没有GPS保持空白，结果为拍摄坐标，不调用地图服务。
保留“读取原图地点”的按需系统权限入口。当前没有新增专用拍照/实时定位功能。用户填写的地点、已保存后清除的地点不会被自动覆盖；异步读取也不会覆盖编辑中的手动输入。
地点不进入 shareProjection，已有好友图片仍用去元数据的派生JPEG；不修改好友授权或照片服务。
