# 0.7.4 情感化记录与分类优化

本次只实施分类和感受记录；语音只评估。没有部署 SQL、云函数或新服务，没有调用付费 AI。

## 文件
- src/life-expression.mjs：八组感受词、可选自定义词、旧分数显示、默认分类名称映射与空分类删除条件。
- src/core.mjs：默认名称；可选 emotion 校验；个人规则复盘纳入实际感受。旧 mood 1–5 分的均值/趋势只使用原有数值，不从情绪词推测得分。
- src/db.mjs：读取时映射旧默认显示名，不改分类 ID，不覆盖用户改名；事务保护分类删除，禁止删除仍被记录/计划/本地学习条目引用的分类。
- src/views.mjs、life-app.mjs、life.css：分类列表精简，弹窗创建/编辑分类，感受分组选择及自定义词，显示/保存可选 emotion。
- sw.js：增加新模块代码缓存、更新外壳缓存版本；不清除 IndexedDB 用户记录。Android 原有服务工作线程禁用策略不变。
- android-shell/android/app/build.gradle、android-shell/scripts/build-apk.ps1：版本0.7.4-release、versionCode25、对应输出文件名；原包名/发布证书不变。
- tests/life-expression.test.mjs、tests/life-views.test.mjs、scripts/verify-life-expression.mjs：兼容性、隐私边界与真实浏览器交互验证。
- docs/VOICE_MOMENT_ASSESSMENT.md：语音后续方案、改动范围、容量估算及真机要求。

## 产品变化
默认显示名为日常生活、旅途与见闻、学习与成长、消费与好物、心情与感受、运动与活力、生活碎片。默认 ID 保持 daily/travel/learning/spending/wellbeing/fitness/other。旧默认名称在读取时显示为新名称；自定义分类和已自行改过的名称保留。好友按 ID 的权限不变。
目录中空分类只显示“记录第一个片刻”，不再叠加0条/未确认/等待提示；有记录时展示数量与最近日期。空分类内直接提供记录入口。新建分类只留按钮，点击弹窗填写；自定义分类可在详情中编辑，空且无关联项时可删除。
感受先选组，再选具体词；可选“自己写一个词”（20字以内），最近自定义词可在本机输入建议中复用。一次只保存一个感受，也可“暂不记录”。不强迫填写、不做心理诊断。
旧记录未改变选择时，保留原数字和标签。选择新词时写 emotion，mood 为空；新词不推算成分数。个人复盘会列出用户真实填写的词，未记录不会虚构。现有好友发布字段投影和AI摘要保持不变，新情绪字段仅保存在本机个人记录/备份，不额外上传。

## 数据与权限
不需要腾讯云 SQL 或 IndexedDB 版本迁移：只是现有 record 对象增加可选文本字段，旧记录无此字段仍有效。没有修改相册权限、照片整理、保存即同步、好友RPC/RLS或照片云函数。
已有手动报告内容仍按原逻辑保留，不为了更新显示名称覆盖用户编辑过的报告。未关联空分类的删除操作不会迁移或删除任何历史记录。
