# 拾日 0.7.0 · 核心记录旅程（第一阶段）

## 页面级范围
首页以当天状态推荐一个主操作：未记录→开始记录；有待审核→整理当天素材；已保存且没有待审核→回看这一天。发现/保存/复盘三步独立开放，不设锁关、经验值或连续打卡。最近片刻、累计记录天数、按周生活足迹随后展示；全部记录和统计折叠保留。
审核页保留批量选择/排除/撤销/恢复/确认与单张编辑；可视选中标记、随选择数量更新保存按钮。首页进入时清空旧搜索/分类，并限定所选日期，提供查看所有日期。离开审核、导入完成或分类入口重置日期。
保存表单将可选数据和权限配置折叠；权限范围摘要始终可见。保存仍一次完成，不增加发布步骤。保存成功后4秒非阻塞反馈，只在持久化成功后触发；同步状态使用现有 syncLabel，不把本机保存误报云端完成。
成长取真实确认且未排除的记录日期；达到7/30/100/365天或10/50/100/500条记录时给予一次跨阈值反馈。刷新不重放。自动报告不算完成复盘；本次更新后主动保存报告记录 userReviewedAt。旧记录及旧报告保持原样，不回填虚假完成状态。

## 视觉与动效
原创拾日书页/叶片 SVG；沿用深浅色配色，无新库。短过渡约150–250ms；系统减少动态时关闭。没有模态庆祝、竞赛或断签惩罚。按用户补充要求移除次要标签、冗余说明。
