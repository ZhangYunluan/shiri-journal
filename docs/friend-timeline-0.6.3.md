# 0.6.3 好友时间线
修改：src/cloudbase-friends-view.mjs、src/cloudbase-friends.mjs、新增 src/friend-timeline.mjs、life.css；Android 版本及输出名升级。没有修改 SQL、云函数或同步队列。
日期分组只影响显示；文件名样式的标题回退日期文案，不更改原文。同名用户仍通过原账号关系识别。个人主页集中显示身份，所有好友汇总仍保留每条所属好友入口。
照片通过原 api.photo 身份/授权校验，视口附近按需加载，并发最多 2；本机生成最长边 480px 的临时缩略图。云端没有缩略图接口，首次获取仍传输现有云端照片。大图切换重新请求校验权限，支持按钮、方向键和左右滑动。刷新、切页及 401/403/404 清理可控 URL，无法收回已截图内容。
分页沿用现有 feed offset，底部按需加载，保留手动按钮。无新依赖或付费 API。
测试：14 项媒体权限、分享门禁、离线同步回归通过；隔离浏览器验证日期分组、自动图片、标题过滤、图库切换、权限失效清理和手机宽度通过；既有登录/备份/个人流程浏览器回归通过。测试使用本机服务或模拟数据，不代表真实双账号验收。
仍需两台手机验证：同日多片刻、真机手势、海量历史滚动、删除/撤销后刷新、真实第三方拒绝访问、覆盖升级。首次媒体测试因沙箱本机网络 EACCES 失败，允许本机测试连接后全部通过。
