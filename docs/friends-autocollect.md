# 私人采集与每日复盘 · 0.3.0 测试版

拾日以自己的生活节奏和每日复盘为主，健身是子分类，好友近况是辅助功能。

## 使用顺序

1. 安装 shiri-0.3.0-preview.apk，进入「设置与隐私 → 安卓自动采集」，设置 22:00，授权并开启。
2. 国内云服务配置并登录后，独立开启「私人照片自动上传」。压缩照片先进入仅本人可见的账号空间，不直接发布给好友。默认关闭，没有云服务时不可开启。
3. 在时间线或素材库逐张打开照片，核对日期、内容和分类，填写笔记与感受，保存进入自己的复盘。保存日志不等于对好友开放。
4. 想分享时重新打开照片，点击「逐张确认，对亲密好友开放」，再在好友页为指定朋友授权。单张开放与好友权限必须同时成立。
5. 可以收回单张开放或撤销好友权限。恢复备份不会自动恢复分享审批，需要重新确认。

流程：新增照片 → 安卓私有暂存 → 可选自动上传私人库 → 本人核对日志 → 本人逐张确认开放 → 授权好友查看。好友获得“全部开放”也不可见未确认照片。

## 原生能力与限制

- Android 7.0 及以上，需要更新的系统 WebView。沿用原包名和签名，升级前导出备份，不要卸载。
- 首次启用从当天开始，之后补收启用期间遗漏照片。日期按加入相册时间归档，不保证等于拍摄时间。
- Android 14 及以上仅授权部分照片时，新照片需要补充授权。
- WorkManager 以设定时间为目标，不能保证 22:00 准点。锁屏、省电、低电量、强行停止或品牌后台限制可能延后或阻止执行。
- 支持 JPEG、PNG、WebP、GIF，每张不超过 20 MiB。暂存最多 300 张 / 300 MiB，每批采集最多 100 张。HEIC 等格式会标记不支持，系统原图保留。
- 后台生成按日期的数量小结；照片分类/OCR 与内容复盘仍在打开应用后执行，不冒充后台语义识别。
- 上传最长边 640px、去除原图 GPS/EXIF 的 JPEG 压缩预览，原始照片留在手机。压缩副本不等于原图备份。测试私人库最多 2000 张 / 100 MiB，单张预览约 300 KiB。
- 使用 HTTPS，不跟随重定向。端点在构建时配置，后台凭据使用 Android Keystore 加密保存。断网保留队列并重试；登录失效需重新登录和启用。
- 重开应用每批最多导入 30 张至 IndexedDB，成功才清理暂存。未完成上传可由前台补偿。相册原图不删除。
- 暂停上传不会删除私人副本。「清空云端压缩副本」停用上传并删除云端照片及共享副本；「清空生活空间」还删除当前空间本机日志和原生队列。

## 好友权限

ID 为 SR 加 12 位字符，用于搜索，不能代替密码。服务代码实现 ID / 密码模式；微信、短信、邮箱仍需平台配置。暂无找回密码。每个 ID 有独立本地空间，访客记录需备份迁移。

| 范围 | 好友可见 |
| --- | --- |
| 不开放 | 无 |
| 仅手动发布近况 | 好友页主动发布的文字 |
| 指定分类 | 对应分类中已确认开放的照片记录与已发布文字 |
| 全部开放 | 所有已确认开放的照片记录与已发布文字 |

好友申请通过后默认不开放；权限是单向的。共享字段包括标题、笔记、日期、分类、标签、填写的位置、金额、时长、体重、心情分值及压缩照片。不共享密码、原图、备份或内部模型原始文本。

每次读取检查关系、范围和逐张审批。撤回后停止后续访问，不能抹除好友已经保存或截图的内容。私人上传不是实时监控。退出账号停止当前空间采集并清除后台上传凭据。

## 国内部署（尚未部署）

src/social-config.mjs 的 SOCIAL_API 目前为空，APK 不发送账号或上传网络请求，界面明确提示未配置。注册步骤见「国内上线注册指引.md」。局域网下载地址不等于国内公网服务。

后端 social-server 使用 Node 24 / SQLite。在用户名下国内服务器配置 HTTPS 反向代理、持久化磁盘、限流、访问控制、备份及监控。数据库不得放公开站点目录。环境变量 SHIRI_DATA_DIR、HOST、PORT、SHIRI_ORIGINS；APK 来源 https://localhost，禁止通配 CORS，不记录请求正文或 Authorization。

private_photos 以 (owner,id) 为主键，状态 pending / private / approved / deleted。删除保留无照片字节的墓碑，阻止断网重试重新上传已删除内容。共享表只存已开放记录，好友照片从已审批私人库取得。账号注销清除其私人库、会话和关系。

将用户名下 HTTPS API 配置到 SOCIAL_API 后重新打包。构建仅写公开端点到 shiri-cloud.json，不打包服务密钥。网页另配置 CSP。第三方登录、商业上架和正式大陆公网服务仍未完成。
